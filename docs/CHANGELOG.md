# Changelog

## v0.8-dev — 2026-08-02

### Добавлено

- Глобальный поиск по компаниям, контактам, сделкам, активностям и задачам.
- Поиск учитывает разрешения текущего пользователя.
- Модальное редактирование активностей.
- Модальное редактирование задач.
- Право `activity.update`.
- Право `activity.delete`.
- Право `task.update`.
- Soft Delete активностей.
- Фильтрация контактов, сделок и активностей по компании.
- Публичное очищенное зеркало проекта на GitHub.
- Внутренняя Gitea.

### Исправлено

- Viewer больше не может перемещать сделки в Kanban.
- Viewer больше не видит создание активностей.
- Viewer больше не может завершать активности.
- Viewer не видит создание и изменение задач.
- Исправлено исчерпание соединений PostgreSQL.
- Исправлено отображение удалённых активностей.
- После сохранения задачи модальное окно закрывается через переход на список.

### Известные ограничения

- У задач пока нет Soft Delete.
- После сохранения модальных форм используется переход на страницу.
- Нет глобального поиска.
- Нет пользовательских уведомлений.
